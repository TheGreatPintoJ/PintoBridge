# PintoBridge
A clone of Hypixel's Bridge minigame.

## Compatibility
Compatible with spigot and spigot/paper forks, for MC26.3

## Features
- Full Hypixel's Bridge gamemode
- Configurable via `config.yml`
- Easy to scale up teams, and theoretically infinite games

## Getting Started

### Prerequisites
- Spigot or Paper (forks included) server on Minecraft 26.3
- Multiverse-core or other world manager

### Installation
1. Place the JAR file into your server's `plugins` directory.
2. Start/restart your server.

### Configuration

- Edit `config.yml` in the `plugins/PintoBridge/` directory to customize plugin behavior.
- The plugin will generate a default `config.yml` if one does not exist.

### Usage

- The plugin works automatically upon server start.
- When you join any world in config, you will be automatically added to the game.
- Game starts when there are one person on each team.
